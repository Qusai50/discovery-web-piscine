# Discovery Web Piscine

A foundation project about Linux, Git, GitHub, and SSH.
The goal is to learn how to use the terminal, manage files, control versions, and manage repositories safely.

## About This Project

In Project 00, I learned:

- Linux commands and the terminal
- Managing files and folders
- Shell scripting
- Git and GitHub
- Commits and tracking changes
- SSH authentication

## Exercises

- **ex00:** Creating folders and moving between them with the Linux terminal.
- **ex01:** Creating, editing, copying, renaming, and deleting files.
- **ex02:** Creating a Git repository, connecting it to GitHub, and pushing changes.
- **ex03:** Writing project documentation, using the Git workflow, and learning SSH.

## Why Git Makes Development Easier

Git saves the history of changes in a project. It helps me to:

- Track changes and go back to older versions
- Organize my changes with commits
- Work together with other developers
- Save and share my projects with GitHub
